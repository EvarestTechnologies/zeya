# Archived: WHO starter content

These five English and five Kiswahili entries and their ten answer cards were Zeya's runtime content from PR #53 and PR #61. They were written from two WHO "Your life, your health" web pages.

On 27 November 2026 the clinical reviewer, Stella Oiro, did not approve them, because they are not rooted in the Ministry of Health knowledge base (`docs/review/clinical-signoff.md`, item B1). They are kept here with every entry set to `pending`. The build does not read this folder, and they must not be used as runtime content.

They were replaced by Ministry of Health entries in `docs/zeya-knowledge-base.md`, following `docs/work-orders/2026-11-27-guideline-alignment.md`, task 3.
